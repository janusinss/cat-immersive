# Scroll film

## Platform
web

## Purpose
Use the supplied VIDEO.mp4 to create an immersive scrolling experience. Replace large text blocks with short text synchronized to the video. The user confirmed using the video only.

## Scope
One continuous film stage containing 20 sequential moments. Manual scrolling is the default and synchronizes the film, typography, and liquid surround with the page position. Start experience is an optional automatic mode: native video playback at 1x drives the typography and automatic Lenis movement. Wheel, touch, scroll keys, tapping the film, or Escape return control to manual exploration. Resume continues automatic playback from the current position; Restart and Replay explicitly return to the beginning. Controls stay out of the way during manual exploration. Reduced motion retains explicit native playback without automatic page movement or spatial choreography. Additional source footage is not invented.

## Stack
Implementation choice: Vite, React, TypeScript, GSAP, Lenis. No backend or external media.

## Evidence
VIDEO.mp4: 30.24 seconds, 1278 by 720, H.264. Samurai cat running through reeds and onto a boat. Scene labels describe visible action. The Last Paw is an editorial title, not a claimed source title.
